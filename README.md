# -
钢球信息管理系统是一款面向钢球制造企业的生产管理与质量追溯平台，旨在解决传统钢球生产过程中数据分散、质量难以追溯、库存管理混乱的业务痛点。系统涵盖订单管理、生产记录、质量检测、库存追踪、报表统计五大核心模块，帮助企业实现从原材料入库到成品出库的全流程数字化管理。

### 核心特性

- ✅ 前后端分离架构（Spring Boot + Vue.js）
- ✅ JWT 令牌认证 + RBAC 权限控制（按钮级）
- ✅ 钢球精度等级管理（G10/G16/G20...）
- ✅ 多维度质检标准配置（尺寸精度/表面粗糙度/硬度/材料）
- ✅ 出库自动校验 + 人工审核流程（库存校验/批次一致性）
- ✅ 月度销售数据自动汇总 + ECharts 可视化图表
- ✅ 完整业务追溯链路（采购 → 生产 → 销售）

### 登录说明
打开本程序首先进入登录界面，有账号可直接登录，无账号点击注册进行注册登陆。
注意：注册，默认注册普通用户，普通用户无添加用户、删除用户功能；要添加管理员账号必须在数据库添加。
数据库的user表中有学生系统管理员账号：admin，密码为123456，可以用其登录测试。
